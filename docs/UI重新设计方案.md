# UI 重新设计方案

> 版本：v1 ｜ 日期：2026-11-07 ｜ 状态：待用户确认
> 目标：在不动业务逻辑、数据结构与文案的前提下，重新规划视觉语言与页面布局，把「工程账本」概念做透。

---

## 一、现状诊断

读完全局样式与外壳结构后，当前 UI 的主要问题：

1. **视觉语言混杂**：三种气质并存——衬线账本序号（SectionPanel）、深色工程卡（PayslipCard/ResultCards）、泛白 admin 面板（侧边栏 #1b2a3d→#152235 渐变、Element Plus 默认壳）。概念不聚焦，看起来像「账本 + 后台模板」的拼接。
2. **外壳臃肿**：顶栏同时承担 面包屑 + 政策 tag + 年度到手 + 方案下拉 + 保存/应用 + 更多菜单 + 主题切换，一条 bar 七件事；侧边栏与页内 stepper 双重目录（桌面端页内 stepper 还不显示，只剩侧边栏）。
3. **信息层级弱**：字号大量 11–13px；统计卡平铺无重点；insights 结论带、分区 meta 胶囊、面包屑三级导航重复表达同一件事。
4. **层次扁平**：卡片几乎全是 1px 边框白卡，阴影很弱，圆角 6/10/14 混用，页面像表格堆叠，缺少「纸」与「票据」的层次感。
5. **结果区与录入区割裂**：录入是白底表单，结果是深色卡 + 白表，两种视觉没有呼应。

---

## 二、设计方向：把「工程账本」做透

一句话：**录入区是「台账纸」，结果区是「票据」，全站用一套深墨 + 玉绿的账房色。**

视觉三元素：

| 元素 | 用法 | 现状 → 目标 |
| --- | --- | --- |
| 深墨（ink 家族） | 侧边栏、票据卡、页头文字 | 保留，但把侧边栏从偏蓝 #1b2a3d 对齐到 ink-900 #16233a |
| 玉石绿（jade 家族） | 主色、到手/好、激活态 | 保留，收敛使用场景 |
| 纸感（surface/sunken + 细线） | 表单卡、表格、空态 | 强化：白卡改「账本纸卡」（顶部细密行线 + 左侧衬线序号），表格行线更细 |

删除的气质：蓝灰 admin 渐变、无意义的胶囊 tag 堆叠、过小的 11px 正文。

---

## 三、分方案改动清单

### A. 视觉语言统一（P0）

1. **侧边栏重绘**：渐变 #1b2a3d→#152235 改为 `linear-gradient(180deg, #16233a, #0f1a2b)`；品牌标「薪」保留玉绿渐变；激活项改为「左侧 3px 玉绿竖条 + 玉绿底 26%」；折叠态图标居中。
2. **账本纸卡组件（新公共类 .ledger-card）**：白卡 + 1px line 边框 + 顶部一行「纸纹」（repeating-linear-gradient 极淡横线）+ 可选左侧衬线序号。SectionPanel、各编辑器卡片、统计卡统一挂这个类，替换现在散落的 border/radius 手写样式。
3. **票据卡统一**：PayslipCard 与 ResultCards 主卡统一视觉族：`linear-gradient(155deg, #16233a, #1b2c45 58%, #123b38)` + 斜纹防伪底纹 + 玉绿描边高光，两者不再各自为政。
4. **颜色语义表**（写入 global.css 注释并执行）：玉绿=到手/成功/激活；琥珀=税/警告；玫瑰=错误/差额为负；墨蓝=文字/中性。删除任何遗留的蓝色系。
5. **圆角收敛**：卡片 lg 14、控件/小卡 md 10、胶囊 999；不允许 6px 出现在卡片级。

### B. 外壳重构（P0）

1. **顶栏瘦身**：只留「折叠按钮 + 视图标题 + 年度到手大数字 + 方案切换 + 主题切换」。面包屑与政策 tag 移入页面内头部（SetupView/TableView 头部已有账本式 header，把政策版本放它的 meta 胶囊里）。
2. **方案下拉简化**：「存为方案 / 应用 / 更多」三个按钮收进方案下拉旁的单个「方案」下拉菜单（导出/导入/删除/重置并入「更多」）。
3. **侧边栏两级结构**：视图 3 项（录入设置/月度明细/方案对比）+ 本页目录；分组标题用 11px 大写墨蓝灰，去掉多余装饰。

### C. 录入页「台账分栏」（P1）

1. **桌面端分区目录常驻**：把现在只在 ≤960px 显示的 stepper 改为桌面端左侧常驻（侧边栏「本页目录」里已经有，但页面内用「台账页眉」形式再放一条带完成状态 ✓ 的分区条，直接可见 7 个分区 + 完成标记）。
2. **表单卡片流**：每个分区 = 一张账本纸卡（.ledger-card），序号/标题/desc 用现有 SectionPanel 内容，纸卡顶行显示「分区 02 / 07 · 3 项参与计算」。
3. **右侧粘性票据**：PayslipCard 保持票据卡，TargetReverseCard 收进票据卡下方的「小票」样式。

### D. 结果页「票据感」强化（P1）

1. **主票据卡**：ResultCards 主卡与 PayslipCard 同族（方案 A3），把 insights 结论带并进票据卡头部（三格小字：月均到手/到手率/税负率），删除现在独立的 insights 白条。
2. **统计卡**：4 张改为「账本纸卡 + 小图标 + 12.5px label + 21px 数字」，hover 上浮 2px（已有）+ 图标玉绿。
3. **年度双栏**：左表右图保持，但给图表卡挂 ledger-card；el-tabs 若回归也用玉绿下划线样式。

### E. 组件级打磨（P2）

1. **表格**：表头背景 table-head、行 hover sunken、斑马纹用 sunken-2；合计行玉绿浅底 + 顶部 1px 玉绿线。
2. **抽屉**：所有 Drawer 头部统一「账本式」：衬线小序号 + 标题 + 关闭；底部按钮主次分明（主按钮玉绿实心）。
3. **按钮层级**：主操作=实心玉绿；次操作=白底描边；危险=描边玫瑰；图标按钮=无边框 hover sunken。
4. **空态**：统一 el-empty 文案风格「还没有 X，去添加 →」，去重当前零散空态。
5. **动效**：保留 count-up；卡片 hover 统一 0.18s；抽屉/页面切换沿用现有 0.18s fade。

### F. 深色模式（随 P0 同步）

深色下「纸卡」变深墨灰 surface、票据卡不变（本身深色）、行线变低对比——token 已具备，随各方案顺带核对即可。

---

## 四、优先级与实施顺序

- **第一批（P0，先做）**：A（视觉语言统一：侧边栏/纸卡类/票据卡/颜色语义/圆角）+ B（外壳瘦身）。
- **第二批（P1）**：C（录入页台账分栏）+ D（结果页票据感）。
- **第三批（P2）**：E（组件打磨）+ F（深色核对）。

## 五、验收标准

1. `vue-tsc --noEmit` 0 错误；
2. `pnpm test` 153 用例全过（不变量测试保证改动不碰计算）；
3. `pnpm build` 成功；
4. 不新增依赖、不引入外部字体/CDN；
5. 不改变任何文案与数据结构（测试断言依赖文案）。

---

## 六、不改的东西

- 业务逻辑、core/config/stores 数据层（除非视觉联动需要）；
- 所有文案、分区结构、组件职责（视图层已是 views/ 分层）；
- 键盘可达性与 prefers-reduced-motion 尊重。
